About the Challenge

// Briefing

LKSWNSB is an annual Capture The Flag competition designed to test the boundaries of web security knowledge. This challenge — Header Juggling — targets a commonly overlooked attack surface: HTTP response headers.

// Why Headers?

Developers often store sensitive information in HTTP headers without realizing how easily they can be intercepted or exposed. API keys, tokens, internal system names — all can leak through a careless custom header.

In this challenge, an administrator has mistakenly placed a secret flag inside a custom response header. Your job: retrieve it.

// Rules

1. No brute-forcing or fuzzing tools required.
2. The flag format is: LKSWNSB{...}
3. Inspect. Don't guess.
4. Have fun.
